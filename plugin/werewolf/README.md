# 狼人杀插件

机器人主持的网易经典角色、板子狼人杀。**只允许 8、9、10、12 人开局，禁止 11 人及其他人数，房间最多 12 人。**11 人可作为等待第 12 人加入的房间状态，不能开始游戏。

## 创建与选板

```text
创建狼人杀 → 加入狼人杀 → 狼人杀板子 → 狼人杀板子 12人狼王守卫 → 开始狼人杀
夜晚按私聊提示行动 → 白天依次发言 → 放逐投票 → 下一夜
```

- `狼人杀板子` / `狼人杀板型`：查看所有支持的配置及规则。
- `狼人杀板子 完整名称`：房主在开局前选择板子，开局人数必须与板子完全一致。
- `狼人杀板子 自动`：按人数选默认板子：8 人末日捍卫、9 人暗牌场、10 人速推场、12 人标准场。
- `狼人杀角色` / `狼人杀职业`：查看所有角色技能。
- `狼人杀玩家`、`狼人杀状态`、`退出狼人杀`、`结束狼人杀`：查询与管理房间。

游戏开始前所有玩家应添加机器人好友并私聊任意消息。任一身份私聊失败都会取消本次发牌、保留房间名单，重试时重新洗牌。

## 角色与指令

身份、查验结果、夜间目标通过私聊发送。以下夜间指令在多个房间时均可在指令后、动作前加群号，例如 `女巫行动 123456 毒 987654`。

| 角色 | 技能 | 行动指令 |
|---|---|---|
| 平民 | 无夜间技能，通过发言、投票寻找狼人 | 无 |
| 狼人 | 狼队共同袭击一人，可自刀或空刀 | 私聊 `狼人刀人 QQ号` / `狼人刀人 不刀` |
| 预言家 | 查验其他存活玩家阵营，不可重复验人 | 私聊 `狼人查验 QQ号` |
| 女巫 | 解药、毒药各一瓶，全局各一次，每晚只用一瓶；解药用完不再得知刀口 | 私聊 `女巫行动 救` / `女巫行动 毒 QQ号` / `女巫行动 跳过` |
| 猎人 | 被刀、放逐、枪击等出局可开枪；中毒、梦游、殉情不能开枪 | 群聊 `猎人开枪 @玩家` / `猎人不开枪` |
| 守卫 | 守护一人免狼刀，可自守或空守；不能连续两晚守同一人，不防毒；同守同救仍出局 | 私聊 `狼人杀技能 QQ号` / `狼人杀技能 跳过` |
| 骑士 | 全局一次，白天决斗狼则狼出局并天黑，决斗好人则自己出局、继续原发言顺序 | 群聊 `骑士决斗 @玩家` |
| 愚者 | 被放逐时自动翻牌免于出局，此后可发言但不能投票、不能再被投票；刀毒仍有效 | 自动 |
| 狼王 | 参与狼刀，被刀、放逐或枪击后可开枪；被毒、梦游、殉情或自爆不能开枪 | 狼刀指令；群聊 `狼王开枪 @玩家` / `狼王不开枪` |
| 白狼王 | 参与狼刀，白天自爆可带走一人；其他方式出局不能带人，自爆带人双方及关联玩家无遗言 | 狼刀指令；群聊 `白狼王自爆 @玩家` |
| 恶夜骑士 | 参与狼刀，不能自爆、自刀，夜间不出局；被验或被毒反伤一次，同验同毒优先反伤预言家 | 狼刀指令；反伤自动结算 |
| 狼美人 | 参与狼刀，不能自爆、自刀；每晚魅惑另一人，不能连续魅惑同一人；自己出局时目标殉情，被骑士决斗时魅惑无效 | 狼刀指令；私聊 `狼人杀技能 QQ号` / `狼人杀技能 跳过` |
| 摄梦人 | 每晚必须梦游另一人，目标免疫夜间伤害；连续两夜梦同一人，或自己夜间出局，梦游者也出局 | 私聊 `狼人杀技能 QQ号` |
| 噩梦之影 | 每夜优先恐惧一人封锁行动，不能连续恐惧同一人；首夜恐惧前不认识狼队，恐惧狼人使全队空刀 | 私聊 `狼人杀技能 QQ号` / `狼人杀技能 跳过`；狼刀指令 |
| 石像鬼 | 单独查验具体角色，不可重复验人、不认识普通狼队、不能自爆；其他狼人全部出局后获得刀权 | 私聊 `狼人杀技能 QQ号` / `狼人杀技能 跳过`；继承刀权后使用狼刀指令 |
| 守墓人 | 夜间获知上一个白天被放逐玩家的阵营 | 自动私聊 |
| 纯白之女 | 查验具体身份，可重复验人，第二夜起验狼使狼出局 | 私聊 `狼人杀技能 QQ号` / `狼人杀技能 跳过` |
| 狼巫 | 参与狼刀，查验非狼玩家具体身份，可重复验人，第二夜起验到纯白之女使其出局 | 狼刀指令；私聊 `狼人杀技能 QQ号` / `狼人杀技能 跳过` |
| 奇迹商人 | 全局一次赠予另一人一次性查验、毒药或守护；给到狼时对方不获技能，商人次日出局 | 私聊 `狼人杀技能 查验 QQ号` / `狼人杀技能 毒药 QQ号` / `狼人杀技能 守护 QQ号` / `狼人杀技能 跳过` |

幸运儿是附加能力，不改变原来的角色和阵营。发送 `狼人杀技能 幸运 QQ号` 使用技能，或 `狼人杀技能 保留` 留到以后；原角色技能仍使用原指令。幸运儿与原有守卫/女巫/查验技能的重复目标限制同时生效。

所有可开枪玩家按顺序处理，可形成猎人、狼王连锁，全部处理完才继续遗言和胜负结算。暗牌板子不会因为开枪就将狼王公开为猎人。

## 胜负与板子规则

- **8 人末日捍卫**：屠城，首夜无狼刀。
- **8 人诸神黄昏**：屠城，采用娱乐场的出局翻牌版本，首夜有狼刀。
- **10 人狩猎潜狼**：屠城，所有猎人出局才判狼人胜利。
- **其余已实现板子**：屠边，平民全部出局或神职全部出局，狼人获胜。
- 所有狼人（包括特殊狼人）全部出局，好人获胜。**狼人数达到好人人数不会提前判胜。**
- 8/9/10 人板子女巫仅首夜可自救；12 人板子女巫全程不可自救，**12 人纯白夜影例外，仍是首夜可自救**。
- 纯白之女与狼巫的查验出局不受守卫、解药保护；首夜查验不致死，双方在同夜都能完成行动。

## 群聊流程与网易客户端的区别

本次同步的是上述板子的角色组成、对应技能和基础胜负规则。插件保留机器人群聊主持方式，**没有警长竞选、警徽、1.5 票或吞警徽流程**，不声称完整复刻网易客户端的全部流程。

- 夜间技能按私聊提示提交，伤害统一在天亮结算。特殊技能提交顺序服务于机器人主持，不直接照搬客户端动画顺序。
- 狼队按顺序提交刀口；两狼意见不同由第一狼在原选择中裁决，其余平票为空刀。存活且可与狼队交流的玩家可私聊 `狼队广播 内容`；石像鬼未继承刀权、噩梦之影首夜认狼之前不会收到队友信息。
- 白天依次发送 `狼人杀发言 内容`；房主可用 `狼人杀开始投票` 跳过剩余发言。普通自爆、白狼王自爆、骑士决斗只允许白天发言阶段，投票开始后不能发动。
- `狼人杀投票 @玩家` / `狼人杀投票 弃票`：每轮 3 分钟，未投视为弃票，全员完成提前结算；全员弃票直接天黑；平票重投只允许原候选人，二次平票直接天黑。已翻牌愚者不参与投票，也不再是候选人。
- 狼人、神职、开枪和遗言阶段限时 2 分钟。超时通常视为跳过；摄梦人必须行动，超时随机梦游一名其他存活玩家；商人已用过的赠送技能不会再次提示。
- 保留每夜出局者私聊遗言、白天出局者群内遗言的原有约定（包括非首夜），使用 `狼人杀遗言 内容` 或 `狼人杀遗言 放弃`。白狼王发动带人技能时无遗言。
- 每轮开始公布存活/死亡名单；投票前按天回放整局有效发言，第二天起回放此前发言。普通暗牌板子不公开死亡原因、身份或神职技能目标。
