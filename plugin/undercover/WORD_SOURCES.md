# 公开词库来源与筛选记录

导入日期：2026-09-09。本次从两份公开数据中逐条筛选、规范名称并去重后新增 **260 对**，与原有 756 对合计 **1016 对**。

数据已静态整理到 `words.go`；游戏运行时不请求上游接口。下列版本、文件校验值及记录索引用于复核本次导入，不自动跟随上游更新。

## 筛选方式

- 逐条检查两个词有共同描述空间，同时能通过含义、用途或场景加以区分。
- 排除纯同义词、异体字、简单换序、重复缩写、残缺词语及难以独立描述的组合。相似度分数只供参考，不作为自动入库阈值。
- 对已识别的缩写和别名做本次静态规范化，例如“美式”转为“美式咖啡”、“半马”转为“半程马拉松”。这不是运行时通用同义词识别。
- 按 `canonicalPairKey` 的规则去除正反向和大小写重复，再与现有词库比对；不删除或更改原有词对。
- 分类和 1—3 难度由本项目按游戏用途分配，不是上游数据的标注。本次增加“计算机技术”（3）和“语言文字”（2）分类。
- 原有 SQLite 增量补词和已用词软删除规则继续适用，保留管理员禁用状态及历史使用次数。
